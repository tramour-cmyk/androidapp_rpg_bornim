# Strichliste Werkzeugfehler

Dreimal-Regel (Chef 24.11., 07:37, VORGANGSARCHIV): Werkzeug erst, wenn derselbe Fehler dreimal nachweislich Zeit gekostet hat, und nur mit Chef-Ja. Hier wird gezählt.

Wer einen solchen Fehler von Hand behebt oder vorlegt, meldet ihn Sokrates; Sokrates oder Alter Ego trägt ein. Alter Ego prüft die Liste je Runde; beim dritten Strich legt Alter Ego den Fehler dem Chef vor (Telegram). Eine Zeile je Vorfall, neueste oben.
