Probekampf gegen Wölfe; jeden Zustand tragen der Held und ein Wolf nacheinander (Chef 12.11., 17:02: „das muss intensiver sein“; 17:04: Paket zeigen). Oben links steht, was du siehst: „<Zustand> · Paket: <Effekt>“, danach „<Zustand> · eigen“. Eigen heißt: wie alt gezeichnet, jetzt 1,9-mal größer und deckender, dazu ein farbiger Schein über der ganzen Figur. Am Ende flackert je Schadenszustand einmal der Schaden der Runde auf.

| Zustand | aus dem Paket (Reihenfolge im Film) |
|---|---|
| Brennend | burning (Stylized Effekte), aura_fire (Combat Mega) |
| Vergiftet | poisoned |
| Blutend | bleeding |
| Betäubt | stun_stars, shocked |
| Verlangsamt | chilled |
| Geschwächt | weakened |
| Geblendet | cursed (das Paket hat kein „geblendet“) |
| Betrunken | confused (das Paket hat kein „betrunken“) |

Im Paket „Status Effects“ gibt es außerdem frozen, sleeping, charmed, taunted, marked_target, blessed, haste_aura, regen_aura (für spätere Zustände und Zauber).

**Sag bitte:** Welches gilt je Zustand, Paket (welches) oder eigen? Oder was anders sein soll.
