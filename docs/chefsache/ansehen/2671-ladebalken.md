# 267.1 · Ladebalken in der Blende · Tom · 21.10., 16:08

![Ladebalken: früh, halb, fast voll; rechts ohne Zahl](../bilder/267.1-ladebalken.webp)

Entwurf aus dem echten Code der Blende (Handy, 1080 × 2340), Text oben ist der Ortssatz von heute; die Zitate von Homer (267.1T) kommen an dieselbe Stelle. Unten ein dünner Strich in gedämpftem Gold, der sich von links füllt, mit weichem Schein an der Spitze; darunter klein die Zahl gezeichneter Bilder („77 / 160“). Er zählt Bilder (Held, Boden ringsum, Leute), schätzt keine Zeit. Er erscheint nur, wenn der Held neu gezeichnet werden muss (nach einem Update, neuer Held, neue Ausrüstung) oder die Blende länger als 3 s wartet; sonst Blende wie heute.

Stil: schwarz, gedämpftes Gold, Serife, kein Kreisel (`DESIGN-STIL.md` 42b); Übergänge: Balken blendet mit den Worten ein und aus, springt nie zurück.

Bitte sagen: „passt mit Zahl“, „passt ohne Zahl“ (Bild ganz rechts) oder was anders sein soll.
