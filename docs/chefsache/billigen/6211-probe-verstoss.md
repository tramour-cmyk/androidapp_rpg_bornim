# 621.1 · Eine Probe je Aussehen-Thema: was bei einem Verstoß vor dem Versand gilt · Perikles · 07.11., 20:1x

Geprüft an: https://github.com/tramour-cmyk/androidapp_rpg_bornim/commit/8a5a43875

**Frage:** Vorentscheid billigen?

**Entschieden (Vorentscheid):** Mit Probenregel A (621 A, dein Wort 07.11., 16:4x) hält `probelauf.py` schon den zweiten Lauf je Vorgang an, bisher den dritten. Findet der fremde Helfer vor dem Versand einen Verstoß gegen „Prüfer: ja“ oder eine Auflage aus deinem letzten Urteil (461a, 576), ist der eine Lauf verbraucht: für die Behebung gibt Sokrates einen Lauf frei (480.1), danach geht der Film immer an dich.

**Berührt:** `ROLLE-ENTWICKLUNG.md` (Absatz „Aussehen urteilt nur der Chef“), 480, 480.1, 461a, 576, 389.

## Begründung

Regel A spricht von einer Probe vor dir; ein Lauf, den der Helfer vor dem Versand anhält, hast du nie gesehen. Ohne diese Lücke müsste jeder technische Verstoß eine Rückfrage an dich werden.

## Stärkstes Gegenargument

Damit gibt es doch wieder zwei Läufe je Thema, und Sokrates entscheidet über den zweiten; das weicht Regel A auf. **Entkräftet:** frei wird nur ein Lauf zur Behebung eines gemessenen Verstoßes (keine Geschmacksrunde), und Sokrates hält jede Freigabe im Vorgangsarchiv fest; Diogenes kann sie zählen.

**Umgesetzt:** `8a5a43875` (`probelauf.py` GRENZE 1, `ROLLE-ENTWICKLUNG.md`, `LISTE-UMZUG-348.md`). **Rückbau:** Halbsatz „für die Behebung gibt Sokrates einen Lauf frei“ streichen; dann wird ein Verstoß vor dem Versand eine Rückfrage an dich. **Kosten:** höchstens ein Lauf je Verstoß.
