# 142.1 · AAB für die Play Console: Push auf `main` ohne Gerätetest?
Tom · 25.10., 08:55 · M Veröffentlichung · M?

## Frage

Darf die Änderung am Build-Ablauf ohne Gerätetest auf `main`? Antwort „ja“ oder „nein“.

## Stand

`android.yml` baut neben der APK jetzt auch das AAB (`:app:bundleRelease`, gleicher Upload-Schlüssel, gleicher versionCode). Spiellogik bleibt unverändert. Lauf 1024 auf `claude/tom-142-aab` grün, Artefakt `bornim-aab` (85 MB) liegt vor: https://github.com/tramour-cmyk/androidapp_rpg_bornim/actions/runs/40173324735

## Empfehlung

Ja: Die Änderung betrifft nur den Build-Ablauf, die APK entsteht wie bisher. Danach hat jeder Build auf `main` ein AAB, das du von Hand hochladen kannst.

## Stärkstes Gegenargument

Jedes Artefakt wird um rund 85 MB größer. Wenn das stört, legt ein Schalter das AAB nur auf Zuruf an (z. B. beim Release).
