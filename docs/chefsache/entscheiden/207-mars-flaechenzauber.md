# 207 · MARS: Brennende Hände als Flächenzauber des Magiers?
Sokrates · 19.10., 11:47 · E Kampf · Bau Jerry, Text Homer

Kurz: Der Magier bekommt Brennende Hände (SRD, Grad 1, 3W6 Feuer, Rettungswurf Geschicklichkeit für die Hälfte) als Zauber auf eine ganze Reihe.

**Anlass** (Chef 11:42): „Der Magier hat keinen Flächenzauber aktuell. Somit kann das nicht getestet werden. Wäre aber zum Testen praktisch, oder?“ Einziger Reihenzauber im Code ist der Feuerball, erst ab Stufe 5; im MARS-Probekampf steht der Held fest auf Stufe 3.

**Empfehlung: ja.** Passt ehrlich zu Stufe 3, bleibt später nützlich, macht die Reihen (72.10a.3) testbar, auch für Tester ohne Testreiter (201).

**Stärkstes Gegenargument:** Neuer Zauber heißt Text (Homer), Effektbild, Balance. Billiger: Testschalter „Held auf Stufe 5“ (Feuerball da); verfälscht aber jede Balance-Aussage zu Stufe 3 und hilft Testern ohne Testreiter nicht.

**Berührt:** 72.10a.3, 201, 204.
