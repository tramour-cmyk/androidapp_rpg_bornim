# 376.1 · Kettenhemd der Heldin: so lassen, nachbessern oder Ritterin Platte?
Sokrates · 01.11., 20:45 · E Figuren

Frage aus Spikes Blatt 376.1 (in Git vor 40abb488a).

**Frage:** Kettenhemd der Frau so lassen, nachbessern oder die fertige Ritterin Platte (408)?
**Votum Sokrates:** nachbessern als Teil von 463, keine eigene Probe: Durchdringung wie beim Mann (gemessen Frau bis 71, Mann bis 16), Brust nicht durch, nicht flach wie Männerkleidung.
**Berührt:** 376.1, 463, 455.1, 455.2, Grundstand B3/B4.

## Auswertung

- Kettenhemd ist Ladenstück (`chain_shirt`, `LISTE-GEGENSTAENDE.md`) und Tracht der Wachsoldatin; Platte ersetzt beides nicht.
- **Stärkstes Gegenargument:** Platte liegt fertig und spart einen Lauf; sie bleibt als Rüstung, löst aber das Kettenhemd nicht.

**Zu sagen:** „376.1 Kettenhemd nachbessern“, „so lassen“ oder „Platte“.
