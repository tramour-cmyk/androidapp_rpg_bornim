# 147.1 · Nutzungsguthaben auf Pro: aus, Limit oder so lassen?
Perikles · 17.10., 13:36 · B Kosten · Bild Verbrauch Pro (über Ford)
Kurz: Nutzungsguthaben auf Pro ohne Ausgabenlimit (Empfehlung: ausschalten)

**Frage:** Auf deinem Bild steht für Pro: Nutzungsguthaben **an**, „154,37 $ diesen Monat · Kein Ausgabenlimit · Automatisches Neuladen aus“. Damit arbeitet Pro nach dem Abo weiter und kostet extra, ohne Obergrenze. Ob die 154,37 $ schon über das Abo hinaus bezahlt sind, sehe ich nicht. Ist das gewollt?

**Empfehlung: A, ausschalten.** Unser Ziel ist „mit dem Guthaben beider Accounts auskommen“. Ist Pro leer, ist das eine Kennzahl, kein Ausfall (128): Jerry pausiert, Tom übernimmt die Testergebnisse.
- **A** ausschalten
- **B** anlassen mit Ausgabenlimit (Betrag nennst du)
- **C** so lassen

**Stärkstes Gegenargument:** Laut Hinweis auf dem Bild ist Pro „morgen Abend“ leer. Ohne Nutzungsguthaben steht Jerry dann bis zum Wochenwechsel. Dagegen: Jerry hat ohnehin Pause bis Mo 19.10., 21:00. Und braucht es mehr Pro, ist ein festes Limit (B) besser als gar keins.

Berührt: 128, 99, 99e, 147.1.
