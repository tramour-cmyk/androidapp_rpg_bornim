# 99g.1 · Name der Beschlüsse im Repo

Sokrates Projekt · 16.10., 12:56 · fortgeschrieben 13:0x · Anlass Chef 12:5x: „Beschlüsse … das ist ja letztendlich das Archiv der Vorgänge … zukünftig Vorgangsarchiv nennen … keine Bilder samt Dateien … sondern einfach nur … Thema, Entscheidung und unter Umständen eine Begründung“

Kurz: Beschlüsse heißen künftig Vorgangsarchiv, Datei `docs/VORGANGSARCHIV.md`, nur Text, Umzug nach Sa 21:00 (Empfehlung)

**Frage:** Heißen die Beschlüsse künftig **Vorgangsarchiv**, als Datei `docs/VORGANGSARCHIV.md`?

**Empfehlung:** Ja. Chef 13:0x: „Ein Archiv ist ja nichts, was dauerhaft abgelegt ist, sondern es ist halt eher unveränderlich, aber ich kann in meinem Archiv ja nachgucken … wenn wir es Liste-Vorgangsarchiv nennen, ist es wahrscheinlich doppelt genuppelt.“ Das trägt: Einträge werden nicht geändert, nur ergänzt. Ohne Vorsilbe wie `FIRMA.md`. Nur Text (Nummer, Datum, Entscheidung, Leitlinie, ggf. ein Satz Begründung); Bilder und Hörproben bleiben im alten Artefakt („abgelöst“). Das Wort „Beschlüsse“ wird in Regeln und Werkzeugen beim Umzug ersetzt (18 Dateien, mit 102 ohnehin dran).

**Stärkstes Gegenargument:** Neben `ARBEIT-ARCHIV.md` (alte Übergaben, Verlauf) gibt es dann zwei Archive. Der Name unterscheidet sie klar genug.
