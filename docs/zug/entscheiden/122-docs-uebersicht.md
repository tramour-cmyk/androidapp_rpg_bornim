# 122 · Übersicht `docs/README.md` wie bei „Dein Zug“?

Sokrates Projekt · 16.10., 16:54 · Anlass Chef 16.10., 16:4x: „ist es möglich, auf der Ebene Docs auch eine sozusagen Datei zu haben, wie unter zug, … dass ich da die wesentlichen Lines habe“

Kurz: ja, `docs/README.md`, schreibt ein Werkzeug wie bei „Dein Zug“; Empfehlung mit 117 nach Sa 21:00

**Frage:** Soll `docs/` eine Übersicht bekommen, die GitHub unter der Dateiliste zeigt?

**Empfehlung:** Ja. Die Datei `docs/README.md` schreibt eine Action aus der ersten Zeile jeder Notiz neu, wie `docs/zug/README.md`, keine Sitzung pflegt sie von Hand. Inhalt, nach Vorsilbe gruppiert: oben „Dein Zug“ (Zahl offen, Link), Beschlüsse; dann je Datei ein Link mit einem Satz Zweck; bei Vorräten die Kopfzeile („offen n, wartet auf Chef k“). Bauen mit 117 nach Sa 21:00, weil dort ohnehin alle Dateien umbenannt werden.

**Stärkstes Gegenargument:** Eine weitere Übersicht neben `CLAUDE.md` „Wo was steht“ und `LISTE-THEMEN.md`. Weil sie geschrieben, nicht gepflegt wird, veraltet sie nicht und kostet keine Sitzungszeit; dafür braucht jede Notiz eine aussagekräftige erste Zeile (prüft das Werkzeug).
