# 122 · Übersicht `docs/README.md` wie bei „Dein Zug“?

Sokrates Projekt · 16.10., 16:54 · Anlass Chef 16.10., 16:4x: „ist es möglich, auf der Ebene Docs auch eine sozusagen Datei zu haben, wie unter zug, … dass ich da die wesentlichen Lines habe“

Kurz: ja, `docs/README.md` mit ausgewählten Dateien, schreibt ein Werkzeug; Auswahl bestimmt der Chef; mit 117 nach Sa 21:00

**Frage:** Soll `docs/` eine Übersicht bekommen, die GitHub unter der Dateiliste zeigt?

**Empfehlung:** Ja, nur ausgewählte Dateien (Chef 16:5x: „es geht auch nicht um alle Dateien, sondern nur um ausgewählte“). Die Auswahl steht als feste Liste im Werkzeug; die Action schreibt daraus `docs/README.md` neu, keine Sitzung pflegt sie von Hand. Vorschlag für die Auswahl, du streichst oder ergänzt:
1. „Dein Zug“: Zahl offen, Link
2. Beschlüsse (künftig Vorgangsarchiv, 99g.1)
3. Vorräte: nur die Kopfzeile „offen n, wartet auf Chef k“ je Rolle
4. `DESIGN-LEITBILD.md`, `DESIGN-STIL.md` (wie das Spiel sein soll)
5. `LISTE-KAPITEL1.md` (Abnahme Kapitel 1), `LISTE-IDEEN.md`
6. `FIRMA.md`, Prüfbericht Diogenes

Bauen mit 117 nach Sa 21:00, weil dort ohnehin Dateien umbenannt werden.

**Stärkstes Gegenargument:** Eine weitere Übersicht neben `CLAUDE.md` „Wo was steht“ und `LISTE-THEMEN.md`. Weil sie geschrieben, nicht gepflegt wird, veraltet sie nicht und kostet keine Sitzungszeit; Neue wichtige Dateien kommen nur hinein, wenn jemand die Liste ergänzt.
