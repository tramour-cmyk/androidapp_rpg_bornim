# 122 · Übersicht `docs/README.md` wie bei „Dein Zug“?

Sokrates Projekt · 16.10., 16:54 · Anlass Chef 16.10., 16:4x: „ist es möglich, auf der Ebene Docs auch eine sozusagen Datei zu haben, wie unter zug, … dass ich da die wesentlichen Lines habe“

Kurz: `docs/README.md` als Inhaltsverzeichnis von Hand, nur Links auf die wesentlichen Dokumente, ohne Action; mit 117 nach Sa 21:00

**Frage:** Soll `docs/` eine Übersicht bekommen, die GitHub unter der Dateiliste zeigt?

**Empfehlung:** Ja, als schlichtes Inhaltsverzeichnis von Hand, ohne Action (Chef 17:2x: „die wesentlichen Dokumente …, die man fortschreiben will … nur in Art Inhaltsverzeichnis schnell navigierbar … können wir uns den Akt auch sparen, wenn er zu viel Rechenleistung frisst“). Rund zehn Links mit je einem Halbsatz, gruppiert:
- **Jetzt:** Dein Zug, Beschlüsse (künftig Vorgangsarchiv), Prüfbericht
- **Spiel:** Leitbild, Stil, Kampf, Balance, Story-Verzeichnis, Abnahme Kapitel 1, Ideen
- **Firma:** `FIRMA.md`, `CLAUDE.md`

Keine Zahlen und Stände darin, darum veraltet sie nur, wenn eine Datei umbenannt wird oder dazukommt; dann ändert der Umbenennende die Zeile mit. Kostet keine Rechenleistung. Schreiben mit 117 nach Sa 21:00, damit die Links die neuen Namen tragen.

**Stärkstes Gegenargument:** Von Hand gepflegt kann ein Link brechen, wenn jemand umbenennt und die Übersicht vergisst. Selten (Umbenennen ist selten), und ein toter Link fällt sofort auf.
