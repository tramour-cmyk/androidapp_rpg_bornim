# Zugang Kaufrepo

**Zugang Kaufrepo.** Das private Repo `tramour-cmyk/bornim-kaufmodelle` hält die Rohdaten gekaufter Modelle (Version `stufe1`), die gebauten Kaufmodelle je Block (Zweig `bau/<Kennung>`) und die alte Fassung (`kotlin-alt/`). Du brauchst es, wenn du Kaufmodelle baust, einen Sammelbuild machst oder Bilder und Messungen mit Kaufmodellen erstellst (`tools/godot/bau_am_rechner.py --cache --laden`, `docs/LISTE-BAUEN-TESTEN.md`). Kauf-Rohdateien liegen nur dort, nie im Spielrepo. Lizenz: Querprofil Fremde Inhalte.
