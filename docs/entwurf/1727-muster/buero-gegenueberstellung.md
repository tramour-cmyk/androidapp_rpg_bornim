## Was die Gegenüberstellung zeigt

Gemeinsam für beide bleiben nur vier Zeilen: wer im Büro ist und dass es nichts baut, die zwei Werkzeuge, Chefworte wörtlich, Meldeweg in Nummer und Titel. Alles andere tut nur der Disponent oder gilt für alle Sitzungen (Übergabe, Chefwort aus anderer Sitzung: Werkzeug). Der Arbeitsplaner würde im alten Kern Büro 3.1 Zeilen zu `main`, Release, Rückläufern laden, die er nie braucht.

## Frage an den Chef: Kern Büro behalten?

- **A (mein Votum): Kern Büro bleibt, aber schmal** (etwa 0,5 KB, die vier Zeilen). Grund: Disponent und Arbeitsplaner brauchen sie beide; der Sockel kann sie nicht tragen (1.110 von 1.200 Byte); 3.3 so entschieden.
- **B: Kern Büro fällt**, beide Profile tragen die vier Zeilen selbst (wie Rundblick 1734: Sockel + Profil). Spart eine Datei, doppelt vier Zeilen.

Stärkstes Gegenargument gegen A: eine Stufe für vier Zeilen ist „für spezielle Aufgaben ganz spezielle Lösungen“ (Chef 20.11., 07:20). Dagegen: ändert sich der Meldeweg, ändert er sich an einer Stelle für beide („wenn wir den Kern ändern, ändern wir das halt für alle auf einmal“, ebenda).
